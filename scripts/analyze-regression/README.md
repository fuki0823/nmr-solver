# Analyze 候補生成エンジンの回帰テスト

実在の化合物の実測 NMR データを使い、解析パイプライン全体（分子式推定 → 候補取得 → 評価・順位付け）で正解化合物が何位になるかを確かめる。

## 実行方法

```sh
npm run dev                                   # 別ターミナルで開発サーバーを起動
node scripts/analyze-regression.mjs           # 全化合物
node scripts/analyze-regression.mjs rutin     # 指定した化合物だけ(latest.json は更新しない)
```

- 正解の判定には InChIKey の前半14文字（原子のつながり＝骨格）を使う。立体異性体は区別しない。
- 正解の情報は順位の判定にだけ使い、解析処理には渡さない。
- 結果は `results/<日時>.json` に保存する。全化合物を実行した場合は `results/latest.json` も更新し、前回より順位が悪化した化合物があれば表示して終了コード1で終わる。
- PubChem の検索結果は日々変わりうる。PubChem が混雑している場合は警告（⚠）が出るので、その実行結果はアルゴリズムの評価に使わない。
- エンジンを修正したら、必ず全化合物を再実行する。

## データの方針

- 文献やデータベースの実測値だけを使う。値を推定で作らない。
- 構造・分子式・分子量は PubChem で照合する。
- 出典、測定条件、信頼性、データの修正履歴は各 JSON の `source` / `conditions` / `notes` に記録する。
- MS の実測値が無い場合は、PubChem の平均分子量（構造から計算した理論値）を使い、その旨を `input.ms.note` に書く。

### BMRB からの取り込み

```sh
node scripts/analyze-regression/import-bmrb.mjs <bmse ID> <id> <PubChem CID> "<表示名>" "<分類,...>"
```

BMRB（Biological Magnetic Resonance Data Bank）の代謝物エントリには、純品の実測・帰属済みシフトと 2D ピークリストがある。インポーターは次のように変換する。

- ¹³C: 帰属済みの炭素を1原子1本として記録する。
- ¹H: 帰属済みの水素を同じシフト値ごとにまとめ、本数を積分値にする。BMRB の 1D 積分値は規格化されていないため使わない。
- HSQC / HMBC / COSY: 帰属のあるピークは帰属で、座標しかないピークは最も近い ¹H/¹³C ピークで対応付ける。一意に決まらないものは使わない。
- BMRB の InChI と PubChem の構造が一致しない場合は `status: "needs-review"` として評価から外す。

## 修正履歴

### 2026-11-15
- **2D 検証を割当に依存しない方式に変更（D）**: HSQC / HMBC / COSY は、ピークを並び順で機械的に割り当てた結果に頼っていた。そのため、正しい構造が誤ったハード制約で除外されていた（ビタミン D3、ルテオリン、エリスロマイシン）。各相関を説明できる原子の組が候補構造にあるかを、シフト範囲と結合数で判定するようにした。ハード制約は、範囲を広げても説明できない場合だけにした。
- **芳香族・アルケン炭素の範囲の下限を δ95 → 88 に変更（B）**: 5,7-ジヒドロキシフラボノイドの C8（δ93.4〜93.9）を説明できなかった。
- **sp2 C-O の範囲の下限を δ135 → 125 に変更（B）**: フラボノール 3-O-配糖体の C3（δ133）を説明できなかった。
- **分子式の元素比ルールを追加（A）**: Kind & Fiehn 2007 の "Seven Golden Rules"。extended 範囲外は除外、common 範囲外は MS の点数を 0.6 倍にした。無水マレイン酸と C2H2N4O（N/C = 2）の同点が解消した。
- **PubChem の混雑対策（E）**: 混雑エラーを黙って0件にしていたため、正解が候補から消えていた。待ち時間を延ばして再試行し、失敗したら警告を出すようにした。
- **データ修正**: エリスロマイシンの BMRB 帰属で、δ176.161 が C1 と C9 に重複して割り当てられていた。C9 ケトンは実測されていないため、1本を除いた。
- **テストデータ修正**: 既存のハード制約テストで、酢酸エチルの HMBC が4結合の相関（旧割当方式の癖に合わせたもの）になっていた。実際に観測される2〜3結合の相関に直した。
