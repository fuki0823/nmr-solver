# Analyze 候補生成エンジンの回帰テスト

実在の化合物の実測 NMR データを使い、解析パイプライン全体（分子式推定 → 候補取得 → 評価・順位付け）で正解化合物が何位になるかを確かめる。

## 実行方法

```sh
npm run dev                                   # 別ターミナルで開発サーバーを起動
node scripts/analyze-regression.mjs           # 全化合物
node scripts/analyze-regression.mjs rutin     # 指定した化合物だけ(latest.json は更新しない)
```

- 正解の判定には InChIKey の前半14文字（原子のつながり＝骨格）を使う。立体異性体は区別しない。
- 正解の情報は順位の判定にだけ使い、解析処理には渡さない。
- 結果は `results/<日時>.json` に保存する。全化合物を実行した場合は `results/latest.json` も更新し、前回より順位が悪化した化合物があれば表示して終了コード1で終わる。
- PubChem の検索結果は日々変わりうる。PubChem が混雑している場合は警告（⚠）が出るので、その実行結果はアルゴリズムの評価に使わない。
- エンジンを修正したら、必ず全化合物を再実行する。

## データの方針

- 文献やデータベースの実測値だけを使う。値を推定で作らない。
- 構造・分子式・分子量は PubChem で照合する。
- 出典、測定条件、信頼性、データの修正履歴は各 JSON の `source` / `conditions` / `notes` に記録する。
- MS の実測値が無い場合は理論値を使い、その旨を `input.ms.note` に書く。
  - BMRB 由来のデータ: `set-hrms.mjs` で、高分解能 MS を模した測定 m/z とイオン種を入れる。PubChem のモノアイソトピック質量から計算し、化合物ごとに決まった誤差（±3 ppm 以内）を加え、許容誤差は 5 ppm。
  - ユーザー提供のデータと小分子2件: 平均分子量のまま。分子量から分子式を探す経路のテストを兼ねる。

### BMRB からの取り込み

```sh
node scripts/analyze-regression/import-bmrb.mjs <bmse ID> <id> <PubChem CID> "<表示名>" "<分類,...>"
```

BMRB（Biological Magnetic Resonance Data Bank）の代謝物エントリには、純品の実測・帰属済みシフトと 2D ピークリストがある。インポーターは次のように変換する。

- ¹³C: 帰属済みの炭素を1原子1本として記録する。
- ¹H: 帰属済みの水素を同じシフト値ごとにまとめ、本数を積分値にする。BMRB の 1D 積分値は規格化されていないため使わない。
- HSQC / HMBC / COSY: 帰属のあるピークは帰属で、座標しかないピークは最も近い ¹H/¹³C ピークで対応付ける。一意に決まらないものは使わない。
- BMRB の InChI と PubChem の構造が一致しない場合は `status: "needs-review"` として評価から外す。

## 修正履歴

### 2026-11-15
- **2D 検証を割当に依存しない方式に変更（D）**: HSQC / HMBC / COSY は、ピークを並び順で機械的に割り当てた結果に頼っていた。そのため、正しい構造が誤ったハード制約で除外されていた（ビタミン D3、ルテオリン、エリスロマイシン）。各相関を説明できる原子の組が候補構造にあるかを、シフト範囲と結合数で判定するようにした。ハード制約は、範囲を広げても説明できない場合だけにした。
- **芳香族・アルケン炭素の範囲の下限を δ95 → 88 に変更（B）**: 5,7-ジヒドロキシフラボノイドの C8（δ93.4〜93.9）を説明できなかった。
- **sp2 C-O の範囲の下限を δ135 → 125 に変更（B）**: フラボノール 3-O-配糖体の C3（δ133）を説明できなかった。
- **分子式の元素比ルールを追加（A）**: Kind & Fiehn 2007 の "Seven Golden Rules"。extended 範囲外は除外、common 範囲外は MS の点数を 0.6 倍にした。無水マレイン酸と C2H2N4O（N/C = 2）の同点が解消した。
- **PubChem の混雑対策（E）**: 混雑エラーを黙って0件にしていたため、正解が候補から消えていた。待ち時間を延ばして再試行し、失敗したら警告を出すようにした。
- **データ修正**: エリスロマイシンの BMRB 帰属で、δ176.161 が C1 と C9 に重複して割り当てられていた。C9 ケトンは実測されていないため、1本を除いた。
- **テストデータ修正**: 既存のハード制約テストで、酢酸エチルの HMBC が4結合の相関（旧割当方式の癖に合わせたもの）になっていた。実際に観測される2〜3結合の相関に直した。

### 2026-11-15（第2サイクル: 14化合物を追加）
追加直後の結果は、23件中 単独1位15・同点1位6・失敗2。修正後は 単独1位17・同点1位6・失敗0 になり、悪化した化合物はなかった。
- **N・S を含むヘテロ原子2置換の sp3 炭素の範囲を追加（B/C）**: 6-アミノペニシラン酸の C5-H（N,S-アミナール、δ5.49）を説明できず、HSQC のハード制約で除外されていた。C δ45〜100、H δ3.8〜6.4 の範囲を追加した。
- **補助の分子式候補を追加（A/E）**: カフェインは ¹³C が8炭素中5本しか帰属されておらず、炭素数をピーク数+2 以内に絞った段階で正しい分子式が外れていた。第四級炭素は ¹³C で観測されにくいので、超過分の分子式も上位5件だけ別枠で検索するようにした。主候補の検索枠は減らしていない。
- **観測されない第四級炭素への減点を軽く（B）**: ピーク数の不足が候補の第四級炭素の環境数以内なら、減点を軽くした（最大0.3）。
- **メチル基の扱い（C）**: CH3 の H 3個は必ず1本のピーク（積分3以上）に割り当てる。入らないメチル基は不一致として数える。逆方向の「3H のピークはメチル基らしい」は採用しなかった。BMRB のあいまいな帰属やユーザー入力の重なりピークで、正しい構造を減点してしまうため。
- **芳香族 H の範囲の下限をδ5.9 → 5.5（C）**: エピカテキンのフロログルシノール型の環の H6・H8（δ5.69〜5.86）。点数が 76 → 93 に上がった。
- **S の付いた sp3 炭素の上限をδ60 → 72、N の付いた芳香族炭素の下限をδ110 → 100（B）**: ペナム環の C2（δ63.0）、プリンの C5（δ110.0）。
- **丸める前の点数で順位付け（E）**: 総合点を整数に丸めてから比べていたため、約0.5点の差が同点に見えていた。表示は整数のまま、順位は丸める前の値で決めるようにした。無水マレイン酸の同点が解消した。

残っている同点6件は、丸める前の点数でも完全に同じで、今のデータの範囲では区別できない。
- カンファー対フェンコン: どちらも C10H16O のメチル3個を持つ二環性ケトン。HMBC が必要。
- ダウノルビシン対構造異性体: δ2.28（3H）がアセチル基かどうかは、多重度か HMBC が必要。
- ルテオリン: H が芳香族 H 6個しかなく、HSQC も4件だけ。
- ネオヘスペリジン対ヘスペリジン型の異性体: 糖の結合位置の違い。HMBC が必要。
- ニコチン対 3-(ピロリジン-1-イルメチル)ピリジン: N-CH3 があるかどうかは、多重度（s）か HMBC が必要。

### 2026-11-16（第3サイクル: ¹H の多重度の評価）
- **多重度の評価を追加（C）**: `src/lib/analyze/multiplicity.ts` を追加した。¹H ピークの多重度（s / d / t / q / dd / m / br s など）を、ピークを原子に割り当てるときの条件に加える。
  - s: 隣接炭素に H がないこと。メチル基以外は、二面角が90°付近の場合を考えて、隣の H が1個までなら許す。
  - d・t・dd などのパターン: 結合相手の H（³J、隣接 OH・NH、ジアステレオトピックな CH2 の ²J、芳香環・アルケンの ⁴J）が、パターンから決まる下限以上あること。
  - メチル基: s / d / t / q を厳密に判定する（隣が H なし / CH / CH2 / CH3）。
  - m / br s / 記載なし: 判定しない。
  - 合わない割り当ては不一致として減点するだけで、ハード制約にはしない。
- **メチル基を割り当てる順序**: メチル基は、まず多重度が明確なピーク（s / d / t / q）へ置き、残りだけを m・記載なしのピークへ置くようにした。順序がないと、ステロイドのアンギュラーメチル（s）が重なりピーク（m）に入り、正解が減点されていた（コルチゾン、ビタミン D3）。
- **入力**: 貼り付けで多重度を読み取るようにし、ピーク表に多重度の列を追加した。「5.13-5.01」のような範囲表記は中央値にする。
- **テストデータ**: `add-multiplicity.mjs` で、BMRB の 1D ¹H ピークリストの多重度を9化合物に追記した。新しい書式のエントリ（bmse001xxx）は個々の線しか記録しておらず、多重度がないため付けていない。
- **BMRB のメチル基の帰属の補正**: 1つのメチル基の3個の H に別々の値が帰属されているエントリがあった。インポーターで次のように扱う。
  - 値の種類数とメチル基の数が一致する場合は、各メチル基に値を1つずつ割り当てる（カフェインの N-CH3 2個、コルヒチンの OCH3 4個）。
  - 一致しない場合は ¹H の帰属を信頼できないとし、¹H と 2D 相関を入力から外す（エリスロマイシン。13個すべてのメチル基で値が混在していた）。

結果（23件）: 単独1位17・同点1位5・候補外1。
- ニコチンの同点が多重度で解消した（N-CH3 が s）。
- グルタチオン、カフェイン、6-アミノペニシラン酸では、不正解の候補の ¹H の点数が 25〜33 に下がり、差が開いた。
- **エリスロマイシンは候補外**: ¹H と 2D を外したことで、¹³C と分子量だけでは分子式が139通りに残り、正解は58番目で検索範囲（上位25通り）から外れた。¹H も 2D もない複雑な分子では分子式を絞り込めないという、データ不足による限界として記録する。
- **キニジン**: δ1.739 の H が BMRB では s と記載されているが、構造上は隣の炭素に H が2個以上ある CH2 の H で、減点される（94点で1位のまま）。分離しきれていない幅広いシグナルを s と記録したものと考えられる。

### 2026-11-16（第4サイクル: DEPT）
- **DEPT の処理を追加（B）**: `src/lib/analyze/dept.ts` を追加した。
  - ¹³C ピークごとに炭素の種類（C / CH / CH2 / CH3、DEPT-135 の正のピークだけで分かる CH/CH3 など。オフレゾナンス表記の s / d / t / q も可）を入力できる。
  - ピークは、H の数が合う炭素にだけ割り当てる。
  - **ハード制約**: 種類ごとのピークの本数が、候補構造の該当する炭素の数を超えたら除外する。¹³C の本数のハード制約と同じ考え方で、CH/CH3 のような組み合わせについても確かめる。
  - **分子式**: DEPT から求めた炭素上の H の数の下限を、水素数の絞り込みに使う。
- **入力**: ¹³C の貼り付けで「75.0 (CH)」「56.6(CH3)」「35.9 t」のような種類の表記を読み取る。ピーク表に DEPT の列を追加した。
- **テストデータ**: `add-dept.mjs` で、BMRB の DEPT-90・DEPT-135 の実測ピークから種類を付けた（`bmrb-star.mjs` の `carbonTypesFor`）。構造から H の数を逆算することはしない。BMRB の DEPT データには次の癖があり、対処した。
  - **シフトの基準のずれ**: ルテオリンでは約 −0.25 ppm ずれていた。全体のずれを推定して補正する。補正しても DEPT-135 のピークの8割以上が対応しなければ、DEPT を使わない（ネオヘスペリジン）。
  - **位相の反転**: ビオチンでは CH が負になっていた。DEPT-90 に出たピークが DEPT-135 で負なら、符号を反転する。
  - **DEPT-90 への漏れ込み**: 最大強度の3割未満のピークは無視する。強度の記録がない DEPT-90 は使わない。ニコチンで CH2 を CH と数え、ハード制約で正解を除外したため。
  - **検出漏れ**: ルチンでは糖の CH が DEPT-90 で一部検出されておらず、CH3 や C と判定されていた。「出ていない」ことからの推論（DEPT-90 にないから CH3、DEPT-135 にないから C）は使わず、検出されたピークから分かることだけを使う。

結果（23件）: 単独1位17・同点1位5・候補外1（エリスロマイシン、前回と同じ）。
- カンファーの同点は2件 → 1件、ルテオリンの同点は8件 → 4件に減った。
- エリスロマイシンは、DEPT で分かる H の下限（23H）が実際（62H）より大きく下回るため、効果がなかった。古い書式の BMRB には DEPT-90 の強度がなく、どのピークも「CH/CH2/CH3」としか分からないため。
- 実際の論文の DEPT（C / CH / CH2 / CH3 を明示したもの）を入力すれば、炭素上の H の数がほぼ正確に分かり、分子式の絞り込みに大きく効く見込み。

### 2026-11-16（第5サイクル: DEPT の実測値を完全に読んだテスト）
- **DEPT を完全に読んだ変種を追加**: `make-dept-variants.mjs` で `<id>-dept` を作った。対象は、BMRB に DEPT-90 の強度と DEPT-135 の符号の両方がある9化合物（アルテミシニン、ビオチン、カンファー、コルヒチン、エピカテキン、ルテオリン、パルテノリド、ルチン、シンバスタチン）。
  - 通常の読み方（DEPT-90 に出ない正のピーク → CH3、DEPT-135 に出ない → C）で C / CH / CH2 / CH3 を決めた。
  - 同じエントリの実測 HSQC と照らし合わせ、矛盾する判定は緩めた。HSQC の相関がある炭素は C としない。CH3 と判定した炭素の HSQC 相手が3H 未満なら CH/CH3 にする。
  - ネオヘスペリジンは DEPT のピークが2本ずつ並んでおり（C2 のエピマー混合物と考えられる）、¹³C の帰属と対応しないため対象外にした。
- **DEPT の本数のハード制約を、直接観測できる種類だけに限定**: 完全に読んだ変種では、ルチン（C 12本、実際は10個）とシンバスタチン（C 6本、実際は4個）で、DEPT-135 の検出漏れのピークを C と判定していた。その結果、正解が本数のハード制約で除外された（¹H・HSQC は100点だった）。
  - ハード制約の判定では、「出ていない」ことからの推論で決まる C は制約なし、CH3 は CH/CH3 として扱う。
  - 直接観測で決まる CH（DEPT-90）・CH2（DEPT-135 で負）・CH/CH3（DEPT-135 で正）だけで判定する。
  - C と CH3 の誤りは、ピークの割り当てでの減点（ソフトスコア）に任せる。
  - 修正後、ルチンとシンバスタチンはどちらも単独1位（90点）になった。

DEPT の効果（正解 / 最上位の不正解候補の点数。DEPT なしの版は比較のため一時的に作って実行した）:

|---|---|---|---|
| ビオチン | 86 / 78 | 86 / 53 | 86 / 53 |
| アルテミシニン | 93 / 86 | 93 / 78 | 93 / 78 |
| シンバスタチン | 93 / 85 | 不正解の候補なし | 90 / 不正解の候補なし |
| コルヒチン | 93 / 86 | 93 / 84 | 93 / 82 |
| ルチン | 93 / 77 | 93 / 75 | 90 / 70 |
| エピカテキン | 93 / 71 | 93 / 71 | 93 / 68 |
| パルテノリド | 89 / 86 | 89 / 85 | 89 / 85 |
| カンファー | 同点2件 | 同点1件 | 同点1件 |
| ルテオリン | 同点8件 | 同点4件 | 同点4件 |

- DEPT により、正解と最上位の不正解候補の差が広がり、同点が減った。
- 効果の大部分は、直接観測で決まる CH・CH2 から来ている。C・CH3 まで決めた効果は小さく、検出漏れによる誤り（ルチン、シンバスタチン）で正解の点数も下がる。

### 2026-11-16（第8サイクル: ¹³C シフト予測 その2 — sp3 炭素）
- **sp3 炭素の ¹³C 予測を追加**: `prediction/aliphaticIncrements.ts` を追加した。

  - 簡単な化合物での確認: 鎖状アルカンは 1 ppm 以内、ヘテロ原子付きの炭素や6員環は 2〜3.5 ppm 以内。

    - ヘテロ原子が2つ付いた炭素（アセタールなど）
    - 3〜5員環の炭素
    - α・β 位のヘテロ原子が合わせて3個以上ある炭素、ヘテロ原子が付いた第四級炭素。官能基が密集すると増分を足しすぎる。エリスロマイシンの C11 を 99 ppm と予測した（実際はδ80台）。

- **エポキシドの CH の ¹H の範囲を追加**: δ2.4〜3.6 で判定する。パルテノリドの H5 は δ2.9 で、通常の O-CH の範囲（3.0〜5.7）から外れていた。
- **DEPT の C・CH3 は割り当てでも柔らかく扱う**:
  - C・CH3 は DEPT では「出ていない」ことからの推論なので、絶対条件にせず、合わない割り当ては半分の重みの不一致にする。
  - 直接観測で決まる CH・CH2・CH/CH3 は絶対条件のまま。
  - シンバスタチンの DEPT 版で、検出漏れの C が正解を2位に落としていた。

### 2026-11-16（第9サイクル: バンコマイシンとハロゲン）
ユーザーの報告「バンコマイシンがうまくいかない」を受けて、Tian らの論文（Table 1）のデータで調べた。失敗の原因は3つあった。
- **Cl に未対応（A）**: 分子式を生成する元素が C・H・N・O・S だけで、C66H75Cl2N9O24 が原理的に出なかった。
  - 修正: Cl・Br・F・I・P に対応した。MS の入力の「含まれうる元素」で指定した元素だけを探索する。全元素を常に探索すると、バンコマイシンの質量で候補が65万通り、計算に2分かかったため。
  - 不飽和度は C + 1 + (N + P − H − ハロゲン)/2 で計算する。
  - 元素比のルールに F・Cl・Br・I を追加した。I は論文の表にないため、Br に準じた値。
- **探索範囲（A）**: 炭素60・酸素20までだった。炭素150・酸素40・窒素15に広げ、¹³C のピーク数を炭素数の下限にして探索を速くした。
- **Molfile の読み取りの不具合（E）**: V2000 の原子数・結合数の欄を空白区切りで読んでいた。原子が100個を超えると欄がつながり（`101110`）、分子式が壊れた。その結果、正解の候補が「対応していない元素を含む」として、評価の段階で黙って捨てられていた。固定幅の欄で読むように直した（`src/lib/molfile.ts`。Learn モードでも使われている）。

あわせて直したこと:
- **¹³C 予測**: 芳香環に付いた sp3 炭素の置換基は、重原子の数（置換の度合い）で分類する。第三級アルコールの C(OH)R2 は CR3 に近い。
- **¹³C 予測**: OH・OR の隣にハロゲンがある場合の補正を入れた（2-ハロフェノールの実測値から、Cl −4.2、Br −6.5、I −10.3）。
- **対称性**: 小数3桁以上のデータで値が完全に一致する ¹³C の組は、候補構造の等価な炭素の組に対応付けられなければ、半分の重みで減点する。小数2桁以下のデータは偶然の一致が多いので判定しない。

結果（36件）: 単独1位27・同点1位8・2位以下1。悪化した化合物はない。
- **バンコマイシン**: 単独1位（97点）。¹H 60H・¹³C 66本がすべて矛盾なく割り当てられる。
- **トリクロサン**: 単独1位。
- **ハロペリドール**: 塩素がオルト位の異性体と同点。BMRB のデータでは、C-F カップリングで分裂した ¹³C ピーク（130.787 / 130.715 など）が別々の炭素として記録されている。そのため、完全に一致する値の組が、異性体の等価な炭素でも説明できてしまう。
- **テトラブロモビスフェノール A**: 4位。Br の位置が違う、同じく対称な異性体と区別できない。
- これらを区別するには、値が一致する組を等価な炭素に、他のピークと矛盾なく同時に割り当てる「全体の割り当て」が必要。次の課題。
